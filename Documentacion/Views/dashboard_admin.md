# admin.php

Panel principal del administrador. Es lo primero que ve cuando inicia sesión.

## Qué muestra

Tres tarjetas con estadísticas rápidas: total de usuarios, cuántos están activos y cuántos inactivos. Debajo la tabla completa de usuarios del sistema.

## Gestión de usuarios

Desde aquí el administrador puede:
- Crear nuevos usuarios (administrador o cocina) con el botón "Nuevo usuario"
- Editar los datos de cualquier usuario
- Activar o desactivar el acceso de un usuario

Los modales de crear y editar se abren sin recargar la página.

## Sidebar

Tiene acceso a todos los módulos: Usuarios, Productos, Pedidos, Mesas y Ventas e Ingresos.
